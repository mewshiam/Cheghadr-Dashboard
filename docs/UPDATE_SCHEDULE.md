# ⏰ زمان‌بندی به‌روزرسانی

همه زمان‌ها به وقت تهران (Asia/Tehran).

| ورک‌فلو | فرکانس | ساعت اجرا | منبع |
|---------|--------|-----------|------|
| `update-telegram.yml` | هر ۱ ساعت | ۶ صبح تا ۱۰ شب | کانال‌های تلگرام (دلار، تتر) |
| `update-data.yml` | هر ۲ ساعت | ۶ صبح تا ۱۰ شب | tgju.org (طلا، سکه‌ها، انس) |
| `daily-rebuild.yml` | روزانه | ۸:۱۵ صبح | بازسازی کامل تاریخچه |

## نحوه کار

۱. GitHub Actions اسکریپت `build_data.py` را اجرا می‌کند
۲. اگر دیتا تغییر کرده باشد، `data/dashboard_data.json` کامیت و پوش می‌شود
۳. سایت دیتا را مستقیم از `raw.githubusercontent.com` می‌خواند — **بدون نیاز به ری‌دیپلوی**
۴. ری‌دیپلوی Cloudflare Pages فقط وقتی لازم است که کد HTML/CSS/JS تغییر کند

## اجرای دستی

از تب **Actions** در گیت‌هاب → انتخاب ورک‌فلو → **Run workflow**
